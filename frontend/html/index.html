Architecture de la stack

  Navigateur
      │
      ▼  port 80 (exposé)
  ┌─────────────┐
  │    Nginx    │  ← service "frontend"
  │ (proxy)     │     replica : 1
  └──────┬──────┘
         │  réseau overlay "app-net"
         │  /api/*  →  http://api:3000
         ▼
  ┌─────────────┐
  │  Node.js    │  ← service "api"
  │  API        │     replica : 2  (load-balanced)
  └──────┬──────┘
         │  redis:6379  (nom DNS interne)
         ▼
  ┌─────────────┐
  │   Redis     │  ← service "redis"
  │  (cache)    │     NON exposé à l'extérieur
  └─────────────┘
